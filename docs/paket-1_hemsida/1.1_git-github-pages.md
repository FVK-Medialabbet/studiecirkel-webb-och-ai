## Mål

Efter den här modulen ska du kunna:

- skapa ett konto på GitHub  
- logga in på GitHub  
- skapa en egen kopia av en färdig hemsidemall (fork)  
- aktivera GitHub Pages och hitta adressen till din hemsida  
- göra enkla ändringar direkt i webbläsaren och se dem på din sida  

Fokus är att få upp <strong>en första enkel sida på internet</strong>,
inte att lära sig all Git-teori ännu.

## Varför Git och GitHub (kortfattat)

Vi går inte på djupet här, men några grundidéer:

- <strong>Git</strong> är ett system för versionshantering:
  - sparar historik  
  - gör det möjligt att ångra misstag  

- <strong>GitHub</strong> är en tjänst på internet där:
  - du lagrar din kod  
  - kommer åt den var som helst  
  - kan publicera enkla sidor gratis med <strong>GitHub Pages</strong>

Vi återkommer till Git mer ordentligt senare i kursen.

## Steg 1 – Skapa konto eller logga in på GitHub

### Om du inte har ett konto
1. Gå till  
   <a href="https://github.com"
      target="_blank"
      rel="noopener noreferrer">
     https://github.com
   </a>
2. Klicka på <strong>Sign up</strong>
3. Skapa ett gratiskonto:
   - e-postadress  
   - lösenord  
   - användarnamn  
4. Bekräfta via e-post  

När du är klar och inloggad ser du din <strong>GitHub-startsida</strong>.

---

### Om du redan har ett konto
1. Gå till  
   <a href="https://github.com/login"
      target="_blank"
      rel="noopener noreferrer">
     https://github.com/login
   </a>
2. Logga in med ditt användarnamn och lösenord  

När du är inloggad kan du fortsätta till nästa steg.

---

## Steg 2 – Skapa din egen kopia av hemsidemallen (fork)

Nu ska du skapa <strong>din egen version</strong> av hemsidan som du kommer att arbeta vidare med under kursen.

1. Öppna följande länk i en <strong>ny flik</strong>:  
   <a href="https://github.com/FVK-Medialabbet/first-website-template"
      target="_blank"
      rel="noopener noreferrer">
     https://github.com/FVK-Medialabbet/first-website-template
   </a>

2. Klicka på knappen <strong>Fork</strong> uppe till höger

3. Välj:
   - ditt eget GitHub-konto
   - behåll samma namn eller ändra om du vill

4. Klicka <strong>Create fork</strong>

Nu har du fått <strong>en egen kopia av hemsidan</strong> i ditt GitHub-konto.

👉 Gå tillbaka till studiecirkelns instruktioner när detta är klart.

---

## Steg 3 – Slå på GitHub Pages

Nu ska vi göra så att din hemsida syns på internet.

1. I ditt hemside-repo, klicka på <strong>Settings</strong>
2. Klicka på <strong>Pages</strong> i menyn till vänster
3. Under <strong>Source</strong>:
   - välj <strong>GitHub Actions</strong>  
     (eller <code>main</code> + root om den vyn visas)

Efter en kort stund visas en länk, till exempel:

<code>https://ditt-namn.github.io/first-website-template/</code>

Klicka på länken – nu har du en <strong>publicerad hemsida</strong> 🎉

---

## Steg 4 – Gör en ändring på sidan

Nu provar vi hur det känns att uppdatera sidan.

1. Klicka på filen <strong>index.html</strong> i ditt repo  
2. Klicka på <strong>pennan</strong> (Edit this file)  
3. Ändra texten, till exempel rubriken  
4. Scrolla ned och klicka <strong>Commit changes</strong>

Vänta några sekunder och:
- ladda om webbadressen 🔄  
- se hur sidan uppdateras

👉 Tänk på <strong>Commit changes</strong> som din nya <strong>spara-knapp</strong>.

---

## Om något inte syns direkt

Det är normalt.

- vänta upp till någon minut  
- ladda om sidan 🔄  
- kontrollera att du sparade ändringen
